# Полевой каталог предметов — Рёкан (RK-01)

## Предметы и назначение

| Предмет | Где найти | Применение |
|---|---|---|
| Осколок бумажного фонаря | Ворота, бумажный фонарь | Соединить с нитью для оберега или со спичечным коробком для тлеющего фонаря. |
| Мокрая половина ключа I | Сад, чёрный пруд | Соединить со второй половиной ключа. |
| Мокрая половина ключа II | Энгавa, щель в досках | Соединить с первой половиной ключа. |
| Ключ Рёкана | Результат рецепта | Открывает дверь генкана. |
| Записка кукольника | Коридор, записка на стене | Прочитать подсказку о ключе, нити, бумаге и огне. |
| Шёлковая нить | Сад, камень | Повязка, оберег, скрытая строка записки, следы на стене, мирная ветка Паучихи. |
| Спичечный коробок | Генкан, полка | Создать фонарь; зажечь бумажный фонарь на месте. |
| Горькие травы | Сад, папоротник | Соединить с нитью для лечебной повязки. |
| Медный колокольчик | Коридор, полка | Отвлечь существо, помочь Паучихе, разгадать ритм водостока, применить у якоря. |
| Травяная повязка | Травы + шёлковая нить | Самостоятельно восстанавливает 25 здоровья. |
| Тихий оберег | Осколок фонаря + шёлковая нить | Самостоятельно восстанавливает 20 рассудка; применим к якорю. |
| Тлеющий фонарь | Осколок фонаря + спичечный коробок | Включает/выключает свет; освещает зеркало; может быть установлен в якорь. |
| Чёрное семя | Сад, у корней | Опасная находка: снижает рассудок; можно внедрить в якорь. |
| Сшитая маска | Кладовая | Опасная находка: надеть/снять; влияет на существ и рассудок; применима к якорю. |

## Рецепты

1. **Мокрая половина ключа I + мокрая половина ключа II → Ключ Рёкана.** Открывает дверь генкана.
2. **Горькие травы + шёлковая нить → Травяная повязка.** Лечение на 25 HP.
3. **Осколок бумажного фонаря + шёлковая нить → Тихий оберег.** Восстанавливает 20 рассудка.
4. **Осколок бумажного фонаря + спичечный коробок → Тлеющий фонарь.** Свет помогает удержать мысли, но повышает заметность.

## Контекстные применения в Рёкане

- Ключ → дверь генкана.
- Нить → записка и следы на стене.
- Спички → бумажный фонарь.
- Оберег → якорь.
- Тлеющий фонарь → якорь и потемневшее стекло.
- Колокольчик → якорь, водосток и Паучиха.
- Чёрное семя и маска → опасные варианты воздействия на якорь.
- Повязка, оберег и фонарь можно использовать из инвентаря.
- Любой предмет можно оставить в комнате и позднее подобрать.

## Головоломки и секреты

- Записка М. подсказывает порядок: ключ → нить → бумага → огонь.
- Водосток у ворот: три коротких удара и один длинный; ритм можно услышать эхом или проверить колокольчиком.
- Следы на стене сада: подсказка о том, что не всякая тень враждебна; нить выявляет место, где отпечатки прерываются.
- Потемневшее стекло: восстановленный фонарь показывает скрытую фигуру и надпись.
- Слоты предметов поддерживают соединение рецептов; предмет можно перетащить на объект сцены или на свободную часть локации.

## Управление

- ЛКМ по слоту — выбрать предмет; выбрать второй — попробовать рецепт.
- Перетащить предмет на объект сцены — применить к нему.
- Перетащить предмет на свободное место — оставить в этой комнате.
- ПКМ по предмету — осмотр; Shift + ПКМ — выбросить.
- ПКМ по свободной части сцены — эхо.
- **E** — эхо; **Q** — окликнуть; **R** — применить выбранное; **F** — изучить выбранное; **X** — выбросить.
- **1–9** — выбрать слот; в бою клавиши 1–5 остаются боевыми действиями.
